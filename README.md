# Генератор надёжных паролей

Консольное приложение на Python, которое создаёт криптостойкие пароли по заданным параметрам и сохраняет их в файл на рабочем столе.

## Возможности
- Выбор длины пароля (минимум 8 символов)
- Гибкая настройка символов: строчные/заглавные буквы, цифры, спецсимволы
- Сохранение пароля в `password.txt` на рабочем столе  
  - Если файл пуст, пароль записывается без лишнего перевода строки
  - Если файл уже содержит пароли, новый добавляется с новой строки
- Удобный запуск двойным кликом через `run.bat`
- Защита от некорректного ввода (проверка на число, минимальная длина)
- Окно остаётся открытым после генерации, пока не нажмёте Enter

## Как запустить
### Способ 1 (двойным кликом)
1. Скачайте `generator.py` и `run.bat` в одну папку.
2. Запустите `run.bat` двойным кликом.
3. Следуйте инструкциям в консоли.

### Способ 2 (через терминал)
```bash
python generator.py
```
